# [Drone Collaboration] Multi-drone Collaborative Path Planning Based on MASAC Reinforcement Learning Algorithm [with Python Code]

In response to the problem of heterogeneous multi-UAV path planning in dynamic and uncertain environments, a new multi-agent deep reinforcement learning algorithm is proposed. Firstly, an environment for reinforcement learning with multiple UAVs reaching a target location in airspace was developed, incorporating drone dynamics equations and considering the heterogeneity of UAVs as well as safety obstacle avoidance requirements. Secondly, performance metrics such as task completion rate, formation keeping rate, and flight time were designed to measure the algorithm's effectiveness. Subsequently, the multi-UAV path planning problem was modeled as a partially observable Markov decision process (POMDP), and a multi-agent soft actor critic (MASAC) algorithm was proposed to seek an approximate optimal strategy for this problem. Finally, the effectiveness and superiority of the proposed algorithm were verified through simulation experiments.
Introduction
With the rapid development of intelligent decision-making and the performance of airborne equipment, UAVs, as a rapidly growing force in air combat, have become increasingly important due to their zero-damage and excellent maneuverability advantages in modern warfare [1]. Researching related technologies has a significant impact on gaining operational initiative and improving combat performance. Among them, path planning is the most fundamental issue and premise for UAV combat, aiming to quickly and safely reach the target location.
The principle of classic path planning algorithms is simple, and they can generally meet the requirements for path planning in most cases. The Dijkstra algorithm proposed by Dijkstra [3] finds the optimal path through a forward traversal of all nodes. The A* algorithm is an improvement on Dijkstra by Hart et al. [4], which expands nodes based on a specific evaluation function. The D* algorithm is an improvement on A* by Stentz [5], which dynamically updates nodes using an evaluation function after calculating the path to the destination, and replans the next stage's path based on the current state.
Since path planning is an NP-optimization problem [6], classical algorithms can have a dramatic increase in computational complexity in complex environments, and may even be unsolvable, known as the curse of dimensionality. Heuristic algorithms can avoid this issue, and their application in path planning is becoming increasingly widespread [7]. Literature [8] applies a greedy allocation strategy to assign targets to each UAV and applies an improved variable-information ant colony optimization algorithm to path planning. Literature [9] proposes a genetic algorithm parallelly implemented on graphics processing units to solve static environment path planning problems. Literature [10] introduces a new hybrid particle swarm optimization algorithm that merges the simulated annealing algorithm to address path planning problems in complex environments. Both classical and heuristic algorithms are more suitable for solving static path planning problems. However, for dynamic path planning problems, where global environmental information is unknown and real-time planning is required, [11].
The emergence of Deep Reinforcement Learning (DRL) [12∼14] provides a new approach to address dynamic path planning problems. The DRL algorithm, which combines the decision-making capabilities of reinforcement learning [15] with the perception abilities of deep learning, is conducive to path planning in complex and dynamic environments. Literature [16] employs an improved Deep Deterministic Policy Gradient (DDPG) algorithm to solve the path planning problem for parachutes in variable ocean current environments. Literature [17] uses a competitive Deep Q Network algorithm [18] to address the path planning problem with collision avoidance at fixed heights. Literature [19] adopts the Twin Delayed DDPG (TD3) algorithm to solve the adaptive motion planning and obstacle avoidance technology for autonomous underwater robots. Literature [20] employs the TD3 algorithm to enable UAVs to perform path planning tasks in multi-obstacle environments characterized by randomness and dynamics. However, the aforementioned literature all use single-agent DRL algorithms to tackle single drone or multi-drone path planning problems, which makes it difficult to address the collaborative issues among UAVs.
Therefore, in response to the problem of multi-drone collaborative path planning, this paper adopts a multi-agent Deep Reinforcement Learning (DRL) algorithm and proposes a Multi-Agent Soft Actor Critic (MASAC) algorithm. This approach eliminates the dependence on accurate models through data training. The algorithm draws inspiration from the multi-agent DDPG (MADDPG) algorithm proposed by Lowe et al. [21], replacing the DDPG component of MADDPG with a more exploratory Soft Actor Critic (SAC). Compared to previous work, the main contributions of this paper include three aspects:
(1) Traditional classical algorithms cannot avoid the curse of dimensionality, heuristic algorithms are not suitable for solving dynamic path planning problems, and single-agent DRL algorithms struggle to enable agents to learn the ability to cooperate. To address this, this paper uses a multi-agent DRL algorithm to handle the problem of multi-drone collaborative path planning.
(2) There is a scarcity of open-source environments for multi-drone path planning. This paper develops a visual reinforcement learning environment for multi-drone path planning in airspace scenarios. In this environment, UAV movements are constrained by dynamic equations, and the heterogeneity of drones as well as safety obstacle avoidance requirements are also considered.
(3) The paper models the multi-drone path planning problem as a partially observable Markov decision process (POMDP), proposing the MASAC algorithm to solve the POMDP model to obtain joint actions of multiple agents. The experimental results demonstrate the effectiveness and superiority of the proposed algorithm.

Therefore, three categories of subtasks need to be completed for multi-drone collaborative path planning: (1) Avoiding obstacles to prevent collision detection from causing UAV damage; (2) Reaching the target location; (3) Follower UAVs should try their best to keep following the leader within a certain range to maintain the breakthrough formation.

Conclusion 
This paper takes the scenario of heterogeneous multi-drone flying towards the target location in airspace as the research background, developing a visual reinforcement learning environment for multi-drone collaborative path planning. A multi-agent Deep Reinforcement Learning (DRL) algorithm—MASAC—is proposed to train multi-drone for collaborative path planning. The results show that after training, the multi-drone can reach the target location under conditions of maintaining formation, safe obstacle avoidance, and within boundaries. The MASAC algorithm can not only be flexibly applied to different numbers of drones but also achieve higher performance indicators than random strategies and MADDPG algorithms, and realizes synergistic effects. In future work, we will remove the assumption of two-dimensional space and consider the movement of drones in three-dimensional space. Additionally, our work is still in simulation stage, and subsequent applications to actual multi-drone systems can be attempted to address potential challenges in practice.
